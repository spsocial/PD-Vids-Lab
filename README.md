# PD Vids Lab

ส่วนขยาย Chrome ทำคลิปอัตโนมัติด้วย Google Vids — ไม่กินเครดิต Flow (ใช้บัญชี Google ที่มีสิทธิ์ AI video เช่น Google AI Ultra)

## ดาวน์โหลด
โหลดไฟล์ zip ตัวล่าสุดที่หน้า [Releases](https://github.com/spsocial/PD-Vids-Lab/releases/latest)

## วิธีติดตั้ง
1. แตกไฟล์ zip ไว้ในโฟลเดอร์ที่จะไม่ลบทิ้ง
2. เปิด chrome://extensions แล้วเปิด Developer mode (มุมขวาบน)
3. กด Load unpacked แล้วเลือกโฟลเดอร์ที่แตกไว้
4. กดไอคอน PD Vids Lab แล้วใส่ License Key (PDVL-)

## วิธีอัปเดต
เมื่อมีเวอร์ชันใหม่ จะมีแถบแจ้งในหน้าใช้งาน → กดดาวน์โหลด → แตกไฟล์ทับโฟลเดอร์เดิม → กด Reload ที่ chrome://extensions
